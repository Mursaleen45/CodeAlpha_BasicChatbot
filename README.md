# CodeAlpha_BasicChatbot
# Basic Chatbot Using Python

## Project Description
This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users and provides responses based on their messages.

## Features
- Responds to greetings.
- Answers how are you questions.
- Tells its name.
- Displays current date and time.
- Provides help instructions.
- Ends the conversation when the user types bye..

## Technologies Used
- Python
- Functions
- If-elif-else statements
- While loop
- String handling
- datetime module

## How to Run
1. Download the project.
2. Open the folder in VS Code.
3. Open the terminal.
4. Run:

python chatbot.py
